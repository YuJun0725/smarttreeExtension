# 智慧树视频助手

当前版本：**0.1.8**。此版本新增「自动选择最高倍速」，启动助手后自动选择播放器提供的最高速度，切换视频后重新选择。更新后，在扩展管理页面点击本扩展的「重新加载」，再刷新课程页面，确认面板底部显示「版本 0.1.8」。保留 0.1.7 的 AI智慧课程目录适配、MOOC 目录、AI随堂练习关闭和点击事件兼容修复。

Chrome / Edge 浏览器扩展，源代码在 `extension` 文件夹。无需构建、无需配置服务端。

提供自动播放、暂停后续播、自动选择最高倍速、视频结束后切换下一节，以及可选的弹窗随机作答。首次安装默认暂停，最高倍速开关默认开启，仅在助手运行时生效；随机作答默认关闭，启用后每题随机选择一个选项，全部选中后提交。多选题也只选择一个选项，不保证答案正确。

## 安装

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目中的 **`extension` 文件夹**，不要选择项目根目录。
4. 登录智慧树，打开课程视频，**刷新课程页面**。
5. 在页面右下角点击「启动助手」，或点击浏览器工具栏里的插件图标，勾选「启动助手」后保存。
6. 如需自动处理视频中的题目，勾选「弹窗随机作答」。

设置会保存在浏览器本地，对所有智慧树标签页生效。为了明确控制当前课程，建议只打开一个课程播放标签页。助手暂停后停止后续操作，正在播放的视频继续播放；需要暂停视频时请点击播放器暂停，并保持助手关闭。

## 使用说明

如果出现 `Extension context invalidated`，说明扩展更新／重新加载后，当前课程页面仍在使用旧脚本。刷新**课程网页**即可恢复；只刷新扩展管理页无法更新已打开网页中的脚本。新版会显示中文提示和「刷新课程页面」按钮。

- 只有播放器报告 `ended`（播放结束）之后才尝试切换，操作间隔默认 1.5 秒。
- 「自动选择最高倍速」可在右下角面板或插件设置中关闭。根据当前播放器的 AblePlayer / Video.js 倍速菜单选择数值最大的可用选项，例如菜单最高为 1.5× 就选 1.5×，最高为 3× 就选 3×；切换视频或播放器重建后重新检查。通过原菜单的点击处理同步倍速和显示，不添加菜单外的速度。未识别到菜单时保留当前速度；未生效时最多重试三次并提示，不影响自动播放或切换。暂停助手或关闭此开关后停止调整，已选中的速度保留，可在播放器内手动更改。
- 优先点击「下一节」按钮；支持旧版共享课目录及新版 MOOC 的 `.catalog-com` 目录。新版使用 `.chapter-item.current` / `.chapter-content-second.current` 定位当前课程，点击下一行标题区域；下一章折叠时先展开，章节测验不会作为下一节视频点击。下一节加载失败时最多重试同一目标三次，之后显示提示。
- AI智慧课程学习页先查找当前知识点资源列表中的下一视频，识别视频图标和当前高亮卡片；不会将 PDF、音频或其他资源当成下一视频。当前视频是该知识点最后一个视频时，再通过「个性化学习」目录的选中行或「章节」目录的高亮行进入下一知识点。章节折叠时先展开；个性化目录到末尾后会提示手动选择推荐内容。
- 随机作答只处理视频页面内有选项的可见题目弹窗。多个弹窗会优先处理最上层，每个弹窗单独记录答题状态。已有选择时保留原选择，确认选中后点击「提交／确定」；提交后尝试点击「确定／继续学习」等按钮，也支持答题后新出现的独立确认框。填空题、无法识别的题目、答错后仍无法关闭的弹窗需要手动处理。
- 「AI随堂练习」逐题识别 `.ques-list .item > .option`，通过 `.class-question-select.isSelect` 确认选择；每题均有选择后点击「提交作答」。页面显示「已提交」或页脚带完成标记时，直接进入关闭流程，点击该弹窗自己的关闭图标。判断完成时允许按钮处于禁用状态；单纯禁用的「提交作答」按钮不会被误认为已提交。题目没有可识别的选项时会提示具体题号，并保留弹窗等待手动处理。
- 浏览器可能要求先手动点一次视频播放。可以尝试打开「自动播放时静音」；关闭该开关后请手动恢复播放器音量。
- 右下角面板显示主页面状态，插件图标中的状态会优先显示弹窗所在框架，再显示识别到视频的框架。
- 支持智慧树域名及其匹配的 iframe；其他域名的跨域播放器不会获得访问权限。

## 页面结构不匹配时

插件图标 →「页面适配设置」。六个字段均为 CSS 选择器，留空使用内置规则。

| 字段 | 查找范围 | 示例 |
| --- | --- | --- |
| 视频 | 当前页面 / 匹配的 iframe | `video` |
| 下一节按钮 | 当前页面；播放器在 iframe 时也尝试主页面 | `.next_lesson_btn` |
| 题目弹窗 | 当前页面 | `.dialog-test .el-dialog` |
| 题目选项 | 题目弹窗内部 | `.topic-item` 或 `label.el-radio` |
| 提交按钮 | 题目弹窗内部 | `.answer-submit` |
| 继续 / 关闭按钮 | 题目弹窗内部 | `.continue-button` |

选项选择器应匹配每个可点击的选项，并且选中后需要能观察到 `checked`、`aria-checked`、`active`、`is-checked` 或已支持的选中图标。自定义按钮选择器会直接选择其匹配的按钮，请精确定位。保存时会检查 CSS 语法，但无法验证你填写的选择器是否符合课程页面。

## 验证范围

本项目使用本机 Chrome 和 Playwright，在模拟课程页面验证了播放／续播、播放结束后切换、目录切换、禁用按钮、停止重试、随机作答、保留已有选择、题目复用、反馈弹窗、暂停助手、自动播放限制和设置保存。新版 MOOC 的测试根据公开组件结构构造，覆盖 5.3 → 5.4、三级小节、跨章展开、标题高亮变化后仍重试同一目标以及禁用课程行。框架状态汇总及主页面切换委托使用模拟扩展 API 验证。

AI智慧课程的模拟测试根据公开的学习页组件构造，覆盖个性化目录、知识点内的多段视频、视频资源识别失败、下一资源禁用、跨知识单元展开和无关翻页按钮。尚未在登录后的真实课程中验证这些流程。

最高倍速测试参考智慧树公开的 [AblePlayer 播放器组件](https://lc.zhihuishu.com/ableVideoPlayerAiv2/js/videoPlayer.min.js)及 Video.js 菜单结构，覆盖隐藏的下拉菜单、数值排序、禁用选项、当前播放器范围、设置开关、视频切换与重建、菜单延迟加载、失败重试及弹窗期间等待。当前共 62 项模拟测试，尚未在登录后的真实课程中验证倍速功能。

5.4 → 5.5 的回归测试包含公开页面中的 `PointerEvent` / `isTrusted` 事件判断及 3 秒后返回首页的行为，验证新版点击方式不会进入该分支。也检查了页面存在无关 `.next-btn` 时仍优先点击课程目录。

**尚未登录真实课程完成端到端验证。** 不同课程版本的 DOM、播放器和弹题流程可能不同，不能保证直接适配每门课程。代码只调用网页的播放和点击功能，实际学习进度是否记录由平台决定。

## 开发与测试

需要 Node.js 20 或更新版本：

```powershell
npm ci
npm run check
npm test
```

测试默认查找 Windows 下的 Chrome / Edge；也可以通过 `CHROME_PATH` 指定浏览器，或运行 `npx playwright install chromium` 安装测试用浏览器。

扩展仅申请 `storage` 和 `activeTab` 权限，脚本限定在智慧树域名。没有远程脚本、账号密码读取、进度上报接口调用或向外发送数据的逻辑；测试依赖不需要一起安装到浏览器。

实现参考：[Chrome 内容脚本文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。平台适配线索来自[智慧树公开课程入口](https://studyvideoh5.zhihuishu.com/)、[新版 MOOC 入口](https://wisdom-mooc.zhihuishu.com/study/index)及[AI智慧课程入口](https://ai-smart-course-student-pro.zhihuishu.com/)的公开组件、样式；这些线索无法替代登录后的真实课程验证。
