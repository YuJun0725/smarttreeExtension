智慧树视频助手 v0.1.8
适用于电脑上的 Chrome（谷歌浏览器）和 Microsoft Edge。

本版新增「自动选择最高倍速」。启动助手后，自动选择当前播放器倍速菜单提供的最高速度，切换视频后重新选择。
例如菜单最高为 1.5× 就选择 1.5×，最高为 3× 就选择 3×。实际选项以课程页面为准。

一、首次安装
1. 将压缩包解压到固定文件夹，保留 extension 文件夹。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择本包的 extension 文件夹，不要选择上一级目录。
5. 登录智慧树，打开课程视频并刷新课程网页，然后点击右下角「启动助手」。

二、更新已有插件
1. 用本包 extension 中的文件覆盖原安装目录中的插件文件，或重新加载本包的 extension 文件夹。
2. 在扩展管理页点击「重新加载」，再刷新课程网页。
3. 确认右下角面板底部显示「版本 0.1.8」。

三、最高倍速
1. 「自动选择最高倍速」默认勾选，仅在助手启动后生效。
2. 可在课程右下角面板或浏览器插件设置中关闭。
3. 面板会显示倍速选择结果；未找到可用菜单时保留当前速度。
4. 倍速未生效时最多重试三次，可手动选择，或暂停后重新启动助手再试。
5. 暂停助手或关闭倍速开关会停止后续调整，已经选中的速度保留，可在播放器里手动更改。

四、其他功能
支持自动播放与续播、视频结束后切换下一节、可选的弹窗随机作答，以及已适配题目提交后的关闭流程。
首次安装默认暂停，随机作答默认关闭；随机选择不保证正确，多选题也只选择一个选项。
设置对同一浏览器中的智慧树标签页生效。建议一次只打开一个课程播放标签页。
暂停助手不会暂停正在播放的视频，需要暂停时请使用播放器按钮。

五、验证范围
已通过语法检查和 62 项模拟浏览器测试，尚未在登录后的真实课程中完成端到端验证。
课程播放器和页面结构可能不同；以实际页面运行结果为准。
本包不包含账号、浏览器配置、开发依赖或测试产物。
